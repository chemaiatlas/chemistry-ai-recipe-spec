# Contributing

Thank you for helping shape an open chemistry recipe specification.

1. Open an issue before major changes; include a real chemical task and the problem to solve.
2. For field changes, explain backward compatibility and provide a valid manifest example.
3. Run `python -m unittest discover -s tests -v` before submitting a pull request.
4. Keep scientific claims scoped and cite evidence. Do not imply experimental validation from schema conformance.
5. Never commit credentials, private structures or unpublished experimental data without permission.

Discussion is welcome from chemistry practitioners, tool developers, standards specialists and platform operators. This is an early community draft; maintainers review proposals in public issues and pull requests. A formal governance process is still to be agreed.
